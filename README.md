## 🧱 项目结构

```
tesla-m3-used-monitor/
├── index.html                    # 看板页面（自动渲染，含每日简报）
├── render.py                     # 简报渲染脚本（REPORT/UPDATE_TIME → index.html）
├── tesla_m3_monitor.py           # 官网数据抓取监控脚本（VIN/价格/里程/配置）
├── README.md                     # 本说明
└── .github/workflows/
    └── receive-report.yml        # 接收 repository_dispatch，自动渲染+部署
```

## 🔄 更新机制

```
每日监控脚本抓取官网 → 生成简报 → repository_dispatch 推送
        → GitHub Actions 渲染 index.html → 自动 commit/push → GitHub Pages 刷新
```

### 手动触发
```http
POST https://api.github.com/repos/LZQ-98/tesla-m3-used-monitor/dispatches
Authorization: token <你的PAT>
Content-Type: application/json

{
  "event_type": "submit-report",
  "client_payload": {
    "update_time": "2026-11-01 18:09:07",
    "report": "【目标匹配✅】...\n【基线】..."
  }
}
```
